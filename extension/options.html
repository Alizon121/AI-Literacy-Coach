How to get a free Groq API key
  1. Go to console.groq.com and create a free account.
  2. In the left sidebar, click API Keys, then Create API Key.
  3. Copy the key (it starts with gsk_) and paste it into the field above.
  4. Click Save settings — coaching will activate immediately.
How to set up a local Ollama backend
  1. Install Ollama from ollama.com and follow its setup wizard.
  2. Open a terminal and pull your chosen model: ollama pull phi4-mini
  3. Open another terminal, cd backend, and start the LLM server ollama serve
  4. In the project directory, install the backend: pip install -r backend/requirements.txt
  5. Start the server: cd backend && fastapi dev main.py
  6. Leave that terminal running, then click Save settings above.
